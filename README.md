# AI-помощник для подготовки товарных описаний (КИП)

Прототип сервиса на Python, который по входным данным о контрольно-измерительном приборе (КИП) создаёт структурированный черновик карточки товара для B2B-интернет-магазина через Bothub API (модель DeepSeek V4 Flash).

## 🚀 Установка и запуск

1. Убедитесь, что у вас установлен Python 3.8+
